What the program does

DP4-type methods give each candidate a probability, and this probability is usually read as confidence. In 3,100 recomputed assignments a call of 99% or more was right in 87% of the cases. The program replaces the percentage by a statement that keeps its promise:

  1. Run DP4 or DP4+ as usual and keep the unrounded probabilities of all candidates.
  2. Take the cut-off c of your workflow, from the paper or from your own calibration.
  3. Keep every candidate i with ln(Pbest/Pi) ≤ c·N, where N is the number of shifts.
  4. Report the set with its level. One structure is an assignment; several are the list that further experiments have to separate.

What the level means. Sets built this way contain the actual structure, on average, for at least the stated share of molecules that are like the calibration molecules and are computed with the same workflow.

What it does not mean. It is an average over molecules, not a statement about one molecule. It is conditional on the list of candidates: if the actual structure was not proposed, no set can contain it. For molecules with more than four candidates, or with more shifts than the calibration molecules, report the 90% set.

Rounded input. When a value was rounded so far that a candidate can be neither kept nor excluded, the program keeps it and says so.

Files the program reads

FileWhat is taken from it
DP4+ Excel sheet (.xlsx)The stored values of the row “DP4+” for all isomers, with all digits, and the number of experimental shifts. Save the sheet in Excel after filling it in.
Results of DP4+App (.xlsx)The probability of every nucleus from the sheets “p_sca” and “p_uns” (ten decimals), from which the unrounded likelihood is rebuilt. The sheet “results” alone keeps four decimals.
Output of PyDP4 or DP4-AIThe listed errors of the scaled shifts. The likelihood is computed again with the single Gaussian of PyDP4 (2.269 ppm for carbon, 0.187 ppm for proton), the model of the DP4 workflows of the paper.
Typed valuesProbabilities on any common scale, or logarithms of likelihoods. The number of digits you type sets the precision of the result.
